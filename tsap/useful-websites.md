The **Useful Websites** page is a growing list of websites and online tools that we explore for their potential usefulness in the work of The Sunil Abraham Project (TSAP). These resources may support research, website development, coding, digital preservation, cybersecurity, automation, data analysis, and other project activities.

The list focuses primarily on specialised tools and lesser-known websites that offer practical benefits for TSAP. We have deliberately excluded many popular and commonly known websites, as the aim is to discover and document resources that may otherwise go unnoticed.

Sections and entries within each section are arranged alphabetically.

Inclusion in this list does not imply endorsement or regular use. Websites may be added as we discover, explore, and evaluate them. The list will evolve over time, and resources may be removed if they are no longer useful or relevant.

## GitHub and Repository Tools {#github}
1. [ExplainGitHub](https://explaingithub.com/), provides an AI-powered workspace for understanding a repository through code-aware questions, onboarding reports, and architecture exploration. [Open the TSAP repository in ExplainGitHub](https://explaingithub.com/sunilabrahamindia/sunilabraham).
2. [GitDiagram](https://gitdiagram.com/), generates an interactive architecture diagram of a GitHub repository. [View the TSAP repository diagram](https://gitdiagram.com/sunilabrahamindia/sunilabraham).
3. [GitHub1s](https://github1s.com/), opens a GitHub repository in a browser-based, VS Code-like interface for navigating and searching source files. [Open the TSAP repository in GitHub1s](https://github1s.com/sunilabrahamindia/sunilabraham).
4. [GitIngest](https://gitingest.com/), converts a GitHub repository into a text digest that can be used for AI-assisted code analysis. [Generate a digest of the TSAP repository](https://gitingest.com/sunilabrahamindia/sunilabraham).
5. [GitMCP](https://gitmcp.io/), provides an MCP endpoint that lets compatible AI assistants retrieve documentation and code from GitHub repositories to help answer project-specific questions. [Open the TSAP repository's GitMCP endpoint](https://gitmcp.io/sunilabrahamindia/sunilabraham).
6. [GitReverse](https://gitreverse.com/), analyses repository information to generate an AI prompt that can help recreate a similar project. [Try GitReverse with the TSAP repository](https://gitreverse.com/sunilabrahamindia/sunilabraham).
7. [Octotree](https://www.octotree.io/), adds a file-tree interface to GitHub repositories to make browsing source code easier. [Browse the TSAP repository on GitHub](https://github.com/sunilabrahamindia/sunilabraham) with the Octotree browser extension.
8. [Uithub](https://uithub.com/), turns a GitHub repository into structured, AI-friendly context, with options to filter files and control the output format or token budget. [Open the TSAP repository in Uithub](https://uithub.com/sunilabrahamindia/sunilabraham). Check its current sign-in requirements and permissions before sharing private repository content.

## Images and Mapping {#images-and-mapping}
1. [EXIF.im](https://exif.im/), an online image metadata viewer that helps inspect EXIF information such as camera details, capture time and, when present, GPS coordinates. Review metadata before publishing photographs, since location data may reveal sensitive information.
2. [uMap](https://umap.openstreetmap.fr/), lets you create and share interactive maps using OpenStreetMap data. Maps can include markers, descriptions and layers, and can be embedded in webpages to document places and local points of interest.

## Online Code Editors and Compilers {#online-code-editors}
1. [OneCompiler](https://onecompiler.com/), an online code editor and compiler that lets you write, run, and test code in multiple programming languages without installing them locally.

## Python Development Resources {#python}
1. [Awesome Python](https://awesome-python.com/), a searchable, categorised guide to Python frameworks, libraries and tools, covering areas such as AI, web development, data analysis, automation, testing and security.

## Self-Hosting and Open-Source Software {#self-hosting}
1. [Awesome Selfhosted](https://awesome-selfhosted.net/), a curated directory of free software and web applications that can be hosted on your own servers. Useful for discovering self-hosted alternatives for collaboration, documentation, automation, privacy and digital preservation.

## System Administration, Networking and Security {#system-administration}
1. [crt.sh](https://crt.sh/), searches public TLS certificate transparency records. It can help researchers inspect certificate history and discover subdomains associated with a domain.
2. [The Book of Secret Knowledge](https://github.com/trimstray/the-book-of-secret-knowledge), a curated collection of command-line tools, networking resources, system administration utilities, security references, tutorials and technical guides.

## Text Analysis and Research {#text-analysis}
1. [Voyant Tools](https://voyant-tools.org/), a browser-based text analysis environment for exploring a collection of articles, speeches or other documents. It helps reveal word frequencies, recurring phrases, changes in vocabulary and relationships between terms through interactive visualisations. Useful for analysing written material as part of research and documentation.

## Web Research and Development {#web-research}
1. [PublicWWW](https://publicwww.com/), a source-code search engine for discovering websites that contain particular HTML snippets, scripts, widgets or tracking codes. Useful for web research, investigating website implementations and discovering how specific technologies are used across the web.
2. [urlscan.io](https://urlscan.io/), analyses a submitted URL in an automated browser and reports details such as a screenshot, network requests, loaded resources and connected domains. Useful for investigating website behaviour and external connections. Public scans can expose the submitted URL and results, so avoid submitting private or sensitive links.
